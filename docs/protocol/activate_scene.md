# 执行场景（activate scene）

> 本文仅描述“场景执行”链路（`scene_id` 如 `0d00/0e00`），不包含设备开关命令。  
> 设备开关请见：`docs/protocol/control_device.md`

## 1. 业务说明

- 业务目标：执行指定场景（示例：餐厅开灯/关灯场景）。
- 触发时机：用户点击场景按钮。

## 2. 协议映射

- 请求：`proto_type=4`, `link_code=9`
- 执行后状态推送：`proto_type=5`, `link_code=12`
- 心跳：`proto_type=6`, `link_code=13/14`

关键 TLV：
- `Operate_Type(16)=5`
- `Scene_Desc(2)=scene_id`（如 `0d00`、`0e00`）
- 推送中 `Device_State(11)=1/0`

## 3. 场景执行请求样本（历史抓包）

### 3.1 场景开灯请求

```text
231e00646f6f79617368637001040978000d001000010005020004003064303023
```

### 3.2 场景关灯请求

```text
231e00646f6f7961736863700104097a000d001000010005020004003065303023
```

解读：
- `16=5`：场景执行操作
- `2="0d00"/"0e00"`：场景 ID

## 4. 关联说明

- 同样是 `4/9` 通道，还承载“设备命令执行”业务（`16=1,4(mac),9(cmd)`）。
- 为避免混淆，已拆分到独立文档：`control_device.md`。
